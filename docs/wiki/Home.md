# Building Local AI Architectures

Welcome to the **Building Local AI Architectures** wiki. This is a comprehensive technical resource for engineering robust, enterprise-grade, decentralized AI systems that run entirely on local, offline hardware.

## 📚 Course Overview

This textbook bridges the gap between running simple AI chat scripts and building real-world, production-ready AI systems. Rather than relying on cloud APIs, we teach you how to construct highly complex, multi-agent systems using containerized microservices and open-weights models (like Llama 3 or Qwen).

### Core Philosophy

Most AI tutorials focus on calling hosted cloud APIs (like OpenAI) using linear scripts. While easy, this approach fails at scale due to:
- **Cost**: Expensive API calls accumulate quickly
- **Privacy**: Sensitive data flows to external servers
- **Fragility**: Centralized dependencies create bottlenecks

**Our approach**: Build complex, multi-agent systems that run completely locally using:
- ✅ Containerized microservices (Docker)
- ✅ Open-weights models (Llama 3, Qwen)
- ✅ Decentralized peer-to-peer networks
- ✅ Real-time asynchronous event streaming
